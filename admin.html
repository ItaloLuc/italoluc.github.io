Como atualizar o portfólio

  1. Edite seus projetos e salve o rascunho neste navegador.
  2. Exporte o arquivo projects.js.
  3. Abra data/projects.js no GitHub ↗, substitua o conteúdo pelo arquivo exportado e confirme o commit. O GitHub Pages publica a atualização.

Este painel edita uma cópia local. Não precisa de senha e não altera o site publicado sozinho. O rascunho fica neste navegador; exporte para guardar uma cópia.
